# 🎓 CommitToGraduate - Mi Plan de Estudios

Una herramienta visual y táctil para gestionar el progreso de mi carrera universitaria.

## ✨ Características
- **Drag & Drop:** Interfaz tipo Kanban para mover materias entre estados.
- **Progreso en Tiempo Real:** Cálculo automático del % de la carrera.
- **Fuegos Artificiales:** Celebración visual con `canvas-confetti` al rendir materias.
- **Persistencia:** Los datos se guardan en el navegador (`LocalStorage`).
- **Diseño Moderno:** Estética Glassmorphism con modo oscuro.

## 🛠️ Tecnologías
- **SortableJS:** Gestión del arrastre.
- **Anime.js:** Micro-interacciones y animaciones de entrada.
- **CSS Grid & Flexbox:** Diseño responsive sin scroll horizontal.
