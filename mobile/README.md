CommitToGraduate - Expo skeleton

Instrucciones rápidas:

1. From the project root: cd mobile
2. Install dependencies: npm install
3. Start Expo (web): npx expo start --web

Notas:
- This is an initial skeleton. Next steps: convert full UI to React Native components, add drag-and-drop libraries (react-native-draggable-flatlist for mobile and react-beautiful-dnd for web), and centralize persistence with a shared adapter.
